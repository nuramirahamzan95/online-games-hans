Sudoku Mini 4×4

Isi setiap kotak dengan nombor 1 hingga 4. Kotak jadi hijau kalau betul, merah kalau salah.

Pilih nombor

Cara main

  1. Tekan satu kotak kosong, kemudian tekan nombor 1, 2, 3 atau 4.
  2. Setiap baris, lajur dan petak 2×2 mesti ada nombor 1, 2, 3 dan 4. Setiap nombor sekali sahaja.
  3. Kotak merah boleh ditukar. Cuba nombor lain sampai jadi hijau.
Betul Salah, cuba lagi Kotak dipilih

Papan kekunci: 1–4 isi nombor, ←↑→↓ gerak, Backspace padam.
